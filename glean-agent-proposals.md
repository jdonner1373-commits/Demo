## Top 5 Agent Proposals (Ranked by Impact)

### 🏆 #1 RECOMMENDATION: EMEA Sales Command Center Agent

**The Problem:**
- Lee (EMEA Sales VP) constantly asks you questions about largest deals, churn risks, pipeline analysis, account status, etc.
- You manually pull data from Salesforce, Google Sheets, and various reports
- Takes 15-45 minutes per question
- Happens multiple times per week, often urgently before meetings
- Creates context-switching and delays leadership decisions

**The Agent Solution:**
A conversational Glean agent that connects to Salesforce, Google Sheets, Slack, and your existing reports to instantly answer questions like:
- "What are our top 5 new business deals in EMEA right now?"
- "Which deals over $100K are at risk of churning in Q1?"
- "How is the UK performing vs Germany this quarter?"
- "Show me all deals in Commit stage closing next week"
- "What's our total pipeline coverage for next quarter?"
- "Which AEs are underperforming in pipegen this month?"

**Key Features:**
- Natural language queries (Lee can use it too!)
- Real-time Salesforce data integration
- Context-aware responses (knows about EMEA segments, territories, fiscal calendar)
- Auto-formats responses for Slack
- Cites sources (links to Salesforce opportunities, Google Sheets, etc.)
- Learns common query patterns

**Demo Flow:**
1. Ask: "What are our largest at-risk renewals in EMEA?"
2. Agent queries Salesforce, filters by region, analyzes churn indicators
3. Returns formatted list with account names, ARR, close dates, risk factors, owner
4. Ask follow-up: "Which of these has Lee met with recently?"
5. Agent checks calendar/Slack history and highlights relationships
6. Ask: "Draft a Slack message to the account owners"
7. Agent generates personalized messages

**Impact Metrics:**
- Time saved: ~8-12 hours/week (reduces 30-min analyses to 2-min queries)
- Decision speed: Instant vs. next-day for urgent questions
- Self-service: Lee and other leaders can query directly
- Accuracy: Eliminates manual data pull errors

**Why This Wins:**
- ✅ Solves your #1 most frequent pain point
- ✅ High visibility (helps the Sales VP directly)
- ✅ Impressive live demo potential
- ✅ Clear ROI (hours saved + faster decisions)
- ✅ Extensible to other regions/teams
- ✅ Uses all your existing data sources (Salesforce, Sheets, Slack)

### #2: Weekly Forecast Prep Intelligence Agent

**The Problem:**
- You co-lead weekly forecasting calls with all sales managers and functional leaders
- Requires pre-call prep: pulling pipeline data, identifying risks, tracking deal movement
- Must distill EMEA-wide forecast for CRO presentation later in week
- Manual compilation from multiple sources
- Takes 3-4 hours every week

**The Agent Solution:**
Automatically prepares forecast packages before each weekly call:
- Pulls latest Salesforce pipeline data
- Identifies new deals added this week
- Flags deals that slipped or changed forecast category
- Highlights biggest movers (up/down)
- Generates talking points for each sales manager
- Creates CRO-ready summary slides
- Sends pre-read to attendees via Slack

**Demo Flow:**
1. "Prepare this week's EMEA forecast package"
2. Agent shows pipeline by manager, week-over-week changes
3. "What are the biggest risks to this quarter?"
4. Agent identifies commit deals that have been pushing for 2+ weeks
5. "Generate CRO slides"
6. Agent creates 3-slide summary with charts

**Impact:**
- Time saved: 3-4 hours/week
- Better call prep = more productive meetings
- CRO gets cleaner, faster insights

### #3: Territory Carving Reconciliation Agent

**The Problem:**
- Territory carving is your most complex annual project
- Must enforce multiple rules: continuity, equity, holdover policy, churn propensity
- Incorporates feedback from multiple AEs and managers via workbooks
- Requires constant reconciliation to catch conflicts
- Edge cases and "many cooks" create errors
- Manual validation takes days

**The Agent Solution:**
AI-powered territory planning assistant that:
- Validates territory assignments against all business rules
- Flags violations (e.g., AE over account cap, Q1 renewal reassigned incorrectly)
- Analyzes equity across territories (opportunity distribution)
- Tracks all change requests from AEs/managers
- Identifies conflicts when multiple people want same account
- Generates disruption analysis reports
- Suggests optimal assignments based on constraints

**Demo Flow:**
1. Upload territory assignment workbook
2. "Check for rule violations"
3. Agent finds 12 issues (continuity breaks, cap overages, etc.)
4. "Show me territories with inequitable opportunity distribution"
5. Agent highlights 3 territories below/above average
6. "Suggest reassignments to balance"
7. Agent proposes account swaps with minimal disruption

**Impact:**
- Time saved: 20-40 hours during planning season
- Error reduction: Catches violations before go-live
- Fairness: Data-driven equity analysis

**Why This Could Win:**
- Most complex, high-value project
- Shows AI solving really hard constraint optimization
- Prevents costly mistakes
- But: Hard to demo in 10 minutes (complexity is a pro and con)

### #4: Churn Save Command Center Agent

**The Problem:**
- Weekly calls for top 5-6 at-risk accounts
- Manual prep: pulling account history, usage data, contract details, past interactions
- Tracking across Google Sheets quarter tracker
- Coordinating with CS, sales, finance on payment issues
- Workshop-style problem solving

**The Agent Solution:**
Pre-call churn intelligence briefings:
- Identifies at-risk accounts (usage trends, contract value, payment status)
- Summarizes account history (deals, contacts, support tickets, Slack mentions)
- Suggests save strategies based on similar successful saves
- Tracks action items from previous calls
- Updates quarterly tracker automatically
- Sends follow-up reminders to owners

**Demo Flow:**
1. "Brief me on today's churn save accounts"
2. Agent shows 5 accounts with risk scores and context
3. Click on account: sees full history, usage drop trend, save suggestions
4. "What worked for similar accounts?"
5. Agent finds 3 comparable saves with strategies used
6. "Update tracker with today's action items"

**Impact:**
- Time saved: 2-3 hours/week (prep + tracker updates)
- Better save rates: Evidence-based strategies
- Accountability: Auto-tracked action items

### Technical Implementation (Glean Agent):

**Data Sources to Connect:**
1. Salesforce (opportunities, accounts, contacts, forecasts)
2. Google Sheets (your linearity tracker, pipegen reports, churn tracker)
3. Slack (to send formatted responses and search conversations)
4. Google Calendar (to understand meeting context)
5. Your existing Python scripts/CSVs

**Glean Agent Configuration:**

```yaml
Agent Name: EMEA Sales Command Center

Description: Your AI-powered sales operations analyst. Ask me anything about
EMEA pipeline, deals, forecasts, territories, or account performance.

Capabilities:
- Query Salesforce opportunities in real-time
- Analyze pipeline coverage and forecast accuracy
- Identify at-risk deals and churning customers
- Compare AE performance and productivity
- Surface relevant account context from Slack/meetings
- Format responses for executive consumption

Sample Queries:
- "Show me our top 10 EMEA deals by ARR"
- "Which Commit deals are at risk of slipping?"
- "How is Q1 pipeline coverage looking?"
- "What deals closed in the UK last week?"
- "Compare pipegen performance across AEs"
- "Find all renewals over $50K closing next month"

Data Sources:
✓ Salesforce (Production)
✓ Google Sheets (Sales Ops Trackers)
✓ Slack (#emea-sales, #sales-ops)
✓ Google Calendar (Your calendar)
✓ Google Drive (Forecast decks, QBR slides)
```

**Key Glean Features to Leverage:**
- **Contextual understanding**: Knows EMEA = your region, Lee = your VP
- **Multi-source synthesis**: Combines Salesforce + Sheets + Slack
- **Natural follow-ups**: Maintains conversation context
- **Permissions-aware**: Only shows data user has access to
- **Formatting**: Can output tables, bullets, or prose
- **Source citation**: Links back to source records
